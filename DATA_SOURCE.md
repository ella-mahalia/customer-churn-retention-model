# Dataset Source

This project uses the public **IBM Telco Customer Churn** sample dataset.

Original IBM GitHub archive:
`https://github.com/IBM/telco-customer-churn-on-icp4d`

Raw CSV used by the download script:
`https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv`

The dataset contains 7,043 customer records and 21 raw columns. The target is `Churn`.

The repository downloads the raw dataset directly from the IBM archive instead of generating synthetic customer records.
